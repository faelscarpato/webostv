⚡ Como Fazer Deploy do Painel Online (Grátis)

Como este painel é 100% estático e se comunica diretamente com o seu Supabase, você pode hospedá-lo gratuitamente em serviços como Vercel, Cloudflare Pages ou Netlify:

  1. Opção 1 (Vercel CLI): Abra o terminal na pasta do projeto e execute vercel. O arquivo vercel.json já está configurado!
  2. Opção 2 (GitHub): Suba o repositório para o seu GitHub e conecte o projeto na Vercel ou Cloudflare Pages apontando o diretório raiz para apps/manager.
  3. Acesso em qualquer lugar: Uma vez no ar (ex: https://meu-iptv.vercel.app), você gerencia suas listas de qualquer celular ou computador sem precisar ligar o PC de casa!
